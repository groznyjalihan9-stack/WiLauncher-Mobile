# Changelog — WiLauncher for Android

## 0.1.0 — 2026-10-28

First release, based on Fold Craft Launcher 1.3.4.2.

- WiLauncher name, icon, purple theme and own folder `/WiLauncher` on the phone.
- Built-in optimisation mods in every Fabric, Quilt, Forge and NeoForge game: Sodium / Embeddium, Lithium, FerriteCore,
  ModernFix, Entity Culling, ImmediatelyFast. They can't be removed or turned off and come back if deleted by hand.
- Fabric and Fabric API preselected for new games.
- WiLauncher catalog: 36 phone-friendly mods and resource packs in six sections, one-tap install with dependencies.
- Open a mod `.jar` with WiLauncher to add it to the selected game.
- Phone touch layout: stick, big jump, attack / use, sneak and sprint toggles, inventory, drop, chat, pause, camera.
- Mobile defaults for new games (render distance 6, fast graphics, 60 FPS, auto-jump, game language from the phone).
- Offline and Ely.by accounts; Microsoft sign-in hidden (no own client id).
- Own user agreement and privacy policy; updates and catalog from WiLauncher-releases.
